# BorrowBox — QR-Based Inventory Tracking & Analytics

**Master's Research Project | Saint Louis University | March 2026**

## Project Overview
BorrowBox is a collaborative academic project designed to improve inventory tracking, item reservations, and loss prevention for a community lending service.

The proposed solution combines QR-code scanning, automated overdue notifications, inventory dashboards, and predictive analytics.

## Key Features
- QR-based item checkout and return tracking
- Inventory availability monitoring
- Automated overdue alerts
- Interactive analytics dashboards
- Item condition and history tracking
- Predictive analytics using simulated data

## Technologies
Python, pandas, scikit-learn, MySQL, HTML5, JavaScript, Chart.js, GitHub Pages

## Research Findings
Simulation results indicated potential improvements in item availability, overdue management, and inventory loss prevention. These findings represent modeled scenarios rather than live production outcomes.
